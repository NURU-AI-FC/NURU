# Finding a Zenith branch near you

This article shows you how to find nearby Zenith Bank branches and ATMs using location permissions and search filters.

The Branch finder helps you locate Zenith Bank branches and self-service ATMs near your current location or in a specific area.

## How to find a branch or ATM

1. Tap **Branches** in the main navigation bar.
2. Allow location access when prompted so NURU can show nearby places. If location permission is denied, NURU displays Victoria Island by default.
3. Use the search bar to type an area, city, or branch name.
4. Filter results by tapping **Open now**, **ATM**, **Cash deposit**, or **Account opening**.
5. Select a branch from the list or map to view details.

## Branch details available

- Distance in kilometres and estimated driving time.
- Full address and phone contact.
- Opening hours for weekdays and weekends.
- Available services (such as 24/7 ATM, cash deposit, or self-service).
- Expected wait or queue times.

## Getting directions and sharing

- Tap **Directions** to open route directions in your device map app.
- Tap **Call** to call the branch directly.
- Tap **Share** to copy or share the branch location link.
